## 5. Variable-role distinction

The response is **FTM out of FTA**. Relevant primary inputs are FTM, FTA, residual wingspan, barefoot height, combine position, season and player identity. Exact response counts are essential to the likelihood. Correct player-season eligibility determines panel membership. MIN does not define the response, exposure, primary predictor or beta-binomial count likelihood; it defines positive-time eligibility and supplies descriptive coverage summaries.

Validation therefore separates scientific counts, playing-time classification, and season-display reconciliation. Directly corroborated game records and unchanged membership support a prospective field-specific rule without knowing how NBA generates a separate season-minute display. The amendment's justification is this semantic role and observable evidence, **not the magnitude of the discrepancies**.

## 6. New prospective validation rule

A. **Primary counts:** FTM, FTA, 3PM, 3PA and GP must match exactly in the official validation samples/censuses. Unexplained FTM or FTA disagreement blocks inference.

B. **Audited game records:** Player, season, game identity/date, recorded appearance sets and displayed MM:SS must reconcile at the finest successfully retrieved official precision. Any unexplained game disagreement blocks release. Recorded 0:00 stays distinct from empty/missing/DNP. No unobserved finer-clock precision is claimed.

C. **Eligibility:** Positive-total-time player-season eligibility must agree. For an eligible season, aggregate all recorded appearances, including 0:00. Empty/DNP rows are never converted to zero-time appearances. Any eligibility-changing disagreement blocks release.

D. **Season decimal MIN:** Retain and audit as an ancillary representation. Equality between summed displayed game MM:SS and official season decimal MIN is not a release gate when exact primary counts, reconciled audited appearances and available game displays, preserved positive/zero/missing-DNP distinctions, and unchanged eligibility all hold. No numerical tolerance is introduced. An unknown internal mechanism remains a limitation.
