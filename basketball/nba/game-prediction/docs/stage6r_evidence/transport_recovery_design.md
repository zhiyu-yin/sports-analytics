# Stage 6R isolated transport recovery

The unchanged startup `.pth` imports `nba_game_prediction` and installs `sealed_access.BlockedSocket`. When SSL initializes later, `ssl.SSLSocket` inherits that blocked class. Stage 6's temporary rebinding of `socket.socket` cannot change this existing inheritance. A local construction test reproduces the failure with and without that rebinding; class names, identities and MRO are recorded in `tls_root_cause.json`. No network connection is used to reproduce it.

The recovery worker is a fresh `.venv/bin/python -I -S` process. It imports standard-library SSL/socket before adding the fixed virtualenv dependency and project paths. It then imports the unchanged project policy, retaining network blocking by default. Only a verified, single-use Stage 6R capability opens the scoped acquisition interval; afterward the block is restored and the process exits. No SSL internals or historical code are modified. The parent development process remains blocked throughout.

Capabilities require the exact recovery authorization hash, a random nonce, current worker hash and exclusive consumed marker. Part B additionally requires the passed Part A gate and a hash-bound new recovery ledger. An exclusive global recovery-acquisition marker prevents a second acquisition even with a new capability. Request method, URL, NBA parameters and destination are fixed; redirects, environment proxies and HTTP retries are disabled (the maintained Requests adapter default is zero retries). DNS is limited to stats.nba.com in Part B; audited socket connections must use a resolved address on port 443. Part A permits loopback only and rejects the final NBA endpoint. No generic URL or force option exists. This is an application-level accidental-access boundary, not an operating-system defense against deliberate code modification.

The real transport regression starts a local HTTPS fixture with a temporary self-signed localhost certificate, verifies that certificate on the client, resolves localhost, and completes a real TLS handshake and HTTP response. It checks normal blocking, stale inheritance, absent/wrong/consumed capability rejection, final-endpoint rejection during Part A, and blocking after revocation. No final-season NBA data are requested during these tests.

All original Stage 6 files remain untouched. New support, preflight, checkpoint, ledger and output-routing modules live in `stage6r/`. Historical reproduction and final evaluation call the unchanged Stage 6 saved-estimator, feature, metric, bootstrap and calibration functions. Output destinations are routed to Stage 6R; the stopped Stage 6 report/evidence are never reused. No scientific recipe, fit, target definition, feature, model or uncertainty method changes.

The one authorized recovery request runs only after the exit gate and new ledger exist. The worker records the physical-access timestamp immediately before the maintained NBA API call, preserves response bytes before any JSON decode, and exits after acquisition. The guarded parent records the first outcome decode, validates the entire season, and uses saved estimators. A transport or integrity failure stops without retry or subset scoring. A completed evaluation permits one cached, zero-network, zero-fit deterministic replay, not independent confirmation.
